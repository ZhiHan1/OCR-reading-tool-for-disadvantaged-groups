# 模型投放目录

程序**只扫描**这里，不会自动下载或复制文件。把模型放好后，在界面点「重新扫描」。

## 翻译模型 → `模型/翻译/`

把 `.gguf` 文件直接放进 `模型/翻译/`，或按模型名建子文件夹放入。

```
模型/翻译/
└── HY-MT1.5-1.8B-Q6_K.gguf
```

## 语音识别模型 → `模型/语音/`

放入**完整**的 FunASR 模型文件夹（不能只放 `model.pt`）：

```
模型/语音/
└── paraformer-large/
    ├── config.yaml          # 必需：模型结构定义
    ├── model.pt             # 必需：权重
    ├── configuration.json
    ├── tokens.json          # 必需：词表
    ├── am.mvn               # 部分模型需要
    └── seg_dict             # 部分模型需要
```

支持 Paraformer、SenseVoice 系列。

## 自动下载

不想手动下载语音模型时：

```powershell
py -3.14 tools\download_asr_models.py
```

会自动拉取识别模型、`fsmn-vad`（端点检测）和 `ct-punc`（标点）。

## 扫描规则

- 每 3 秒扫描一次，文件大小与修改时间连续两轮稳定后才登记
- 只登记路径，**不复制、不自动加载**
- 标记「移除」只删列表记录，不删除权重文件
- 路径按项目根目录（发布后为 EXE 所在目录）解析，整个文件夹可以整体搬移

## 为什么模型不进 Git

翻译模型约 1.4 GB、语音模型约 860 MB，远超 GitHub 单文件 100 MB 的限制。
请自行获取，并遵守模型发布方的许可证。
